# 推测解码完整流程（含所有疑问点）

## 角色与核心思想

- **小模型**：便宜，负责**串行猜**候选词，并记录自己给每个候选的概率 `Q`。
- **大模型**：昂贵，负责**一次并行验**，算出每个位置的真实分布 `P`，按规则接受/拒绝，在拒绝处或末尾补采一个词。
- **核心思想**：把“必须串行”的采样交给便宜的小模型，昂贵的大模型只做它能并行的验证。**正确性由接受/拒绝规则数学保证，不依赖小模型猜得准不准。**

---

## 阶段零：准备

已有前文 `context = "今天天气"`，本轮小模型猜 `k=4` 个候选。词表简化：`{不错, 很好, 晴朗, 出去, 玩}`。

---

## 阶段一：小模型串行猜词（4 次前向，便宜）

**为什么串行？** 因为采样的结果是下一次前向的输入，有依赖。小模型也逃不掉，只是它便宜。

```
第1次: 输入 [今天,天气]
       前向 → Q₁ = {不错:0.50, 很好:0.25, 晴朗:0.15, 出去:0.06, 玩:0.04}
       采样(累积分布+随机数) → c₁ = 不错
       记录 Q₁(不错) = 0.50

第2次: 输入 [今天,天气,不错]      ← 把 c₁ 接上（串行依赖）
       前向 → Q₂
       采样 → c₂ = 很好
       记录 Q₂(很好) = 0.25

第3次: 输入 [今天,天气,不错,很好]
       前向 → Q₃
       采样 → c₃ = 晴朗
       记录 Q₃(晴朗) = 0.40

第4次: 输入 [今天,天气,不错,很好,晴朗]
       前向 → Q₄
       采样 → c₄ = 出去
       记录 Q₄(出去) = 0.30
```

**小模型交给大模型的“交接包1”**：

```
候选序列: [不错, 很好, 晴朗, 出去]
Q 值: Q₁(不错)=0.50, Q₂(很好)=0.25, Q₃(晴朗)=0.40, Q₄(出去)=0.30
```

**疑问点①：小模型不也有串行依赖吗？**
有，一点没少。加速不来自消除串行，而来自“串行那段的执行者从小模型来干，单价低一个数量级”。

---

## 阶段二：拼输入，交给大模型

```
完整输入 = [今天, 天气, 不错, 很好, 晴朗, 出去]
```

**关键：序列没有空缺，每个位置都有真实 token。** 这是大模型能一次并行算所有位置的前提。没有小模型填好候选，大模型后面位置的输入是空的，算不了。

**疑问点②：小模型猜的词凭什么能直接给大模型验证？**
因为大模型对“任意词接在前文后面”都能算概率。验证就是查这个概率，不需要大模型“本来想生成这个词”。生成是采样，验证是查表，用同一个分布。

---

## 阶段三：大模型一次前向（1 次，贵，并行）

大模型对**整个序列做一次前向**。因为因果注意力（每个位置只能看到它前面的词），每个位置输出一个“下一个词的概率分布”：

```
位置0(今天)   → P₁：今天之后接什么
位置1(天气)   → P₂：今天天气之后接什么          ← 验 c₁=不错 用这个
位置2(不错)   → P₃：今天天气不错之后接什么       ← 验 c₂=很好 用这个
位置3(很好)   → P₄：...不错很好之后接什么        ← 验 c₃=晴朗 用这个
位置4(晴朗)   → P₅：...很好晴朗之后接什么        ← 验 c₄=出去 用这个
位置5(出去)   → P₆：...晴朗出去之后接什么        ← 全接受时的 +1 用这个
```

**这 6 个分布是一次前向并行算出来的，大模型只跑了这一次。** 产出的是**分布，不是词**——它还没“吐”任何词，只是把每个位置的概率表算好放内存里。

**疑问点③：一次前向怎么能算出多个位置的分布？**
Transformer 对整个序列并行做矩阵运算，因果掩码保证每个位置的输出只依赖它前面的词。所以一次前向 = 同时算出所有位置的合法分布。

**疑问点④：验 c₁ 用的是 P₂ 还是 P₃？会不会用“今天天气不错”去验“不错”？**
验 c₁=不错 用的是 **P₂**（前文“今天天气”之后），不是 P₃。每个候选 cᵢ 用的是**它前一个位置**输出的分布，即“它前面的前文”之后的分布。P₃ 是验 c₂=很好 用的。

**疑问点⑤：输入里已经填了 c₁ 后面的词（很好、晴朗、出去），验 c₁ 时不是用了未来信息吗？**
没有。因果掩码保证位置1 的输出 P₂ **只看位置0、1（今天、天气）**，看不到位置2 及以后。序列一次喂入，但每个位置的输出被掩码限制为只看前文。**“一次喂完整序列”和“每个位置只用前文”不矛盾，掩码保证后者。**

---

## 阶段四：逐个位置验证（查表 + 随机数，无前向）

**规则**：候选词 `c`，大模型概率 `P(c)`，小模型概率 `Q(c)`，以概率 `min(1, P(c)/Q(c))` 接受。

**`P(c)` 从哪来？** 就是阶段三产出的、c 所在位置的前一个位置那个分布里、c 那一项的值。**查表，不是新计算。** `Q(c)` 来自阶段一记录的值。

```
验 c₁=不错（用 P₂ 和 Q₁(不错)）:
  P₂(不错)=0.55, Q₁(不错)=0.50
  接受率 = min(1, 0.55/0.50) = 1 → 必接受 ✓  输出 不错

验 c₂=很好（用 P₃ 和 Q₂(很好)）:
  P₃(很好)=0.30, Q₂(很好)=0.25
  接受率 = min(1, 0.30/0.25) = 1 → 必接受 ✓  输出 很好

验 c₃=晴朗（用 P₄ 和 Q₃(晴朗)）:
  P₄(晴朗)=0.10, Q₃(晴朗)=0.40
  接受率 = min(1, 0.10/0.40) = 0.25
  随机数 r=0.61 > 0.25 → 拒绝 ✗
```

**c₃ 被拒，验证停止。c₄=出去 不用验，直接作废。**

**疑问点⑥：验证时大模型采样了吗？采样准不准？**
**验证时不采样，只查概率。** 查概率是确定性的，没有“准不准”。采样只发生在小模型猜词（阶段一）和拒绝后重采（阶段五）、末尾 +1（阶段六）。

**疑问点⑦：验证 c₃ 时前文是“今天天气不错很好”，这两个词是小模型猜的，基于它算 P₄ 对吗？**
对。因为能走到验 c₃，说明 c₁、c₂ **已经在阶段四被接受了**，它们是合法前文。`P₄` 是基于合法前文算的“给定这个前文，晴朗的概率”，前文由谁产生不影响这个概率的值。如果 c₂ 被拒，验证在 c₂ 就停了，根本不会用到 P₄。

**疑问点⑧：验证是从前往后、遇拒即停吗？**
是。前面的候选先验，被接受的才成为合法前文；某个被拒，它后面所有基于“包含它”的前文算出的分布全部作废。**不存在“用被拒的词做前文算出 P 还拿去用”。**

---

## 阶段五：拒绝位置重采（用现成分布采样，无前向）

c₃ 在位置3 被拒，用**阶段三现成的 P₄ 和阶段一的 Q₃** 构造修正分布：

```
P_修正(w) ∝ max(0, P₄(w) - Q₃(w))

P₄ = {不错:0.05, 很好:0.15, 晴朗:0.10, 出去:0.40, 玩:0.30}
Q₃ = {不错:0.05, 很好:0.10, 晴朗:0.40, 出去:0.30, 玩:0.15}

max(0, P₄-Q₃): 不错:0, 很好:0.05, 晴朗:0, 出去:0.10, 玩:0.15
求和=0.30, 归一化: 很好:0.167, 出去:0.333, 玩:0.500
```

**在这个修正分布上采样**（累积区间 + 随机数 r=0.72）→ 落在“玩” → **重采 c₃' = 玩**。

**疑问点⑨：阶段三已经前向完了，阶段五怎么又“算了一个词”？是不是又前向了？**
**没有再次前向。** “前向”是模型算分布（贵，矩阵乘法）；“采样”是拿现成分布抽签（免费，随机数+查表）。阶段五只是在阶段三已经算好的 `P₄` 上做减法、归一化、抽签，**不碰模型参数**。你把“采样出一个词”误当成“前向一次”了。

**疑问点⑩：候选词是小模型按 Q 采的，大模型没按 P 采它，凭什么说结果等于大模型自己生成？**
因为正确性的判据是“最终输出分布 = P”，不是“谁采的”。对任意词 w：

```
最终输出 w 的概率
= 小模型按 Q 采到 w 的概率 × 接受率 + 修正重采补上的概率
= min(Q(w), P(w)) + max(0, P(w)-Q(w))
= P(w)   ✓
```

小模型采的词只是**提案**，`min(1,P/Q)` 接受 + `max(0,P-Q)` 修正重采，把提案的分布精确校正成 P。猜得准只提高接受率（速度），不改变输出分布（正确性）。

---

## 阶段六：组装本轮输出

```
接受的: 不错, 很好
重采的: 玩
作废的: 晴朗, 出去
```

**本轮输出：`[不错, 很好, 玩]`**，推进 3 个词（2 接受 + 1 重采）。

**另一分支：如果 4 个全接受**
位置5 的分布 P₆ 已经算好（前文是完整的 `[...出去]`），**直接在 P₆ 上正常采样一个词**，比如“开心”。本轮输出 `[不错, 很好, 晴朗, 出去, 开心]`，推进 **5 个词 = 4 接受 + 1 新采**。这个“+1”也是在现成分布上采样，没有额外前向。

**疑问点⑪：这个“+1”是大模型多吐的一个词吗？**
是。但它不是“额外前向”，而是阶段三这次前向顺带算出的最后一个位置的合法分布 P₆，不采白不采。**一次前向最多推进 k+1 个词 = k 个接受的 + 1 个新采的。**

---

## 阶段七：更新前文，进入下一轮

```
新 context = [今天, 天气, 不错, 很好, 玩]
```

回到阶段一，小模型基于新 context 再猜 4 个，大模型再验一次。循环直到结束符或最大长度。

---

## 全局数据流总表

| 阶段 | 谁在动 | 产出/交接 | 是否前向 | 代价 |
|---|---|---|---|---|
| 一 | 小模型 | 候选 `[c₁..c₄]` + `Q(cᵢ)` | 4 次小前向 | 便宜×4 |
| 二 | 拼接 | 完整输入序列 | 无 | 免费 |
| 三 | 大模型 | 每位置分布 `P₂..P₆` | **1 次大前向** | 贵×1 |
| 四 | 查表 | 用 `P(c)`、`Q(c)` 算接受率 | 无 | 免费 |
| 五 | 采样 | 拒绝处用 `max(0,P-Q)` 重采 | 无 | 免费 |
| 六 | 采样 | 全接受时末尾 `P` 采 +1 | 无 | 免费 |
| 七 | 更新 | 新 context 进下一轮 | 无 | 免费 |

**大模型前向一轮只一次（阶段三）。其余全是查表、算术、抽签，不碰模型。**

## 所有疑问点速查

| 疑问 | 答案 |
|---|---|
| 小模型也有串行依赖？ | 有，没消除，只是单价低 |
| 小模型猜的词凭什么能验证？ | 大模型对任意词都能算概率，验证是查表 |
| 一次前向怎么算多个位置？ | 矩阵并行 + 因果掩码，每位置只看前文 |
| 验 c₁ 用 P₂ 还是 P₃？ | 用 P₂（前文“今天天气”之后），不是 P₃ |
| 输入填了后面的词，验前面不是用未来信息？ | 掩码隔断，P₂ 看不到位置2及以后 |
| 验证时采样吗？准不准？ | 不采样，只查概率，确定性 |
| 基于小模型猜的词算 P 对吗？ | 能走到这步说明前面已接受，是合法前文 |
| 遇拒怎么办？ | 停止，后面作废，在拒绝处修正重采 |
| 阶段五又“算词”是不是又前向了？ | 没有，是拿现成分布采样，免费 |
| 小模型采的词≠大模型会采的，凭什么无损？ | `min(Q,P)+max(0,P-Q)=P`，分布被校正回 P |
| “+1”是额外前向吗？ | 不是，是阶段三顺带算的末尾分布上采样 |
| 为什么比普通生成快？ | 大模型串行 N 次 → 小模型串行 N 次(便宜) + 大模型 1 次 |

---

## 一句话总括

**小模型串行猜 4 个候选并记录 Q → 拼成完整序列 → 大模型一次前向、靠因果掩码并行算出每个位置的真实分布 P → 从前往后逐个用 min(1,P/Q) 接受/拒绝、遇拒即停 → 拒绝处用 max(0,P-Q) 重采、全接受处用末尾 P 采 +1 → 本轮输出若干词、更新 context 进下一轮。** 大模型一轮只前向一次，其余全是廉价查表和采样；正确性由接受/拒绝规则数学保证（最终输出分布 = P），小模型猜得准只影响速度、不影响正确性。
