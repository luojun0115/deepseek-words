# 缩放定律 08 · Ruan 2024：Observational Scaling Laws and the Predictability of Language Model Performance

> **论文**：Yangjun Ruan, Chris J. Maddison, Tatsunori Hashimoto（Waterloo/Google DeepMind/Stanford），2024-05，NeurIPS 2024 Spotlight · [arXiv:2405.10938](https://arxiv.org/abs/2405.10938)
> **一句话**：缩放律不必自己训几百个模型——拿 ~100 个公开模型当观测数据，把家族差异建模为"算力→能力"的效率系数，就能预测涌现、GPT-4 的 agent 表现、乃至 CoT/自一致性的收益。

## 三分钟速览

- **观测式路线**：白盒缩放律（Chinchilla）控制变量自己训；观测缩放律接受现实模型的异质性、用低维能力空间把它建模掉。
- **涌现可预测**：MMLU 等的"突现"在能力空间里是平滑 S 形——小模型爬到曲线前半段即可外推后半段。
- **跨任务预测**：GPT-4 在 agent 基准上的表现，只用更弱模型的非 agent 基准分数即可精确预测。
- **后训练干预可预测**：CoT、Self-Consistency 的收益随能力增长可外推。
- **对 DeepSeek 系**：DeepSeek 全系持续开源多尺寸 checkpoint，是观测缩放律最理想的样本池之一。
